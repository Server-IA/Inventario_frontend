AppDataGrid

Componente reusable de grilla para módulos de gestión.

Source:

(require("AppDataGrid"))(props) → {JSX.Element}

Description:

  • Grilla reusable basada en MUI DataGrid con soporte para i18n, tipado explícito de columnas y persistencia opcional de visibilidad.

    El componente permite que cada módulo describa sus columnas usando type y headerKey, mientras la grilla resuelve formato, alineación y render visual consistente para tipos como number, date, boolean, status y actions.
